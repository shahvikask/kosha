# Design principles for this scaffold

Section 6A is the design contract. This file does not replace it.

The scaffold keeps the original mark, navy, gold, and teal. It uses Material 3 color roles rather than the default green theme. Sample amounts are labeled as samples. Unknown cost stays unknown.

The light amber candidate `#D97706` failed contrast as small text on ivory, so surrounding controls use a darker copper. The mark itself still uses `#F5C14A`.

No inspiration app was copied. Owner design approval is pending. Self-scored visual rubrics are not recorded, because no screenshot from Compose was captured.
